### 🚀 Featured Project

**Annotate — AI-Powered Meeting & Message Clarity Service**
Backend service that turns meeting transcripts and text messages into structured insights (summaries, key terms, tone notes, action items) using Claude via AWS Bedrock.

- Hexagonal architecture (ports & adapters) separating API, orchestration, domain logic, and infrastructure
- Reusable workflow engine — AI processing flows defined externally as JSON, executed via modular workflow steps
- AWS Bedrock abstracted behind an outbound port, keeping domain/application layers independent of vendor-specific SDKs
- Layer boundaries mechanically enforced with ArchUnit

`Java` `Spring Boot` `AWS Bedrock` `Hexagonal Architecture` `Workflow Engine` `ArchUnit`
